# 指标定义与限制

以下口径对应当前 2017-11-25 至 2017-12-03 样本窗口。所有“用户数”均按 `user_id` 去重；所有比率必须连同分子、分母和适用窗口解释。

## 行为事件数

公式：`事件数 = 清洗后事件行数`。按行为拆分时，分子是对应 `behavior` 的行数；总事件数是所有有效行为行数。该指标没有用户级分母。

**限制：** 一行代表一次记录到的行为，不代表一次会话或一个订单。购买事件数尤其不能等同于订单数；重复行清理也只能按现有五字段判断。

## 活跃用户数

公式：`活跃用户数 = COUNT(DISTINCT user_id)`。按天、小时或类目统计时，去重范围限制在对应分组内。该指标为计数，未除以平台全量用户。

**限制：** 数值只代表确定性抽样中的已观测用户，不能直接外推为淘宝全站规模；跨分组用户可重复出现，因此分组活跃用户不能简单相加。

## 独立行为阶段覆盖

浏览阶段人数为发生过 `pv` 的去重用户；兴趣阶段人数为发生过 `cart` 或 `fav` 的去重用户；购买阶段人数为发生过 `buy` 的去重用户。兴趣覆盖率公式为 `兴趣阶段人数 / 浏览阶段人数`，购买覆盖率为 `购买阶段人数 / 浏览阶段人数`。

**限制：** 三个阶段分别独立统计，不要求同一用户按浏览、兴趣、购买顺序发生行为，也不保证集合嵌套。两种覆盖率的差是总量比较，不是“兴趣未购”交集规模；交集必须另做用户级计算。

## D1 / D3 / D7 活跃留存

每名用户首次被观测到的活跃日记为 `D0`。对偏移日 `d`，分子是在 `D0 + d` 当天再次活跃的合格用户数；分母是 `D0 + d` 仍落在数据窗口内的用户数。分别令 `d = 1、3、7` 得到 D1、D3、D7。

**限制：** 这是窗口内“首次观测”队列的活跃留存，不一定是真实注册或首访留存。窗口左截断会把老用户当作首次出现用户；D7 分母也小于 D1 分母，不能脱离各自合格用户数横向比较。

## 重复购买事件率

公式：`至少有 2 条 buy 事件的用户数 / 至少有 1 条 buy 事件的用户数`。分母仅包括样本窗口内的购买用户。

**限制：** 数据没有订单 ID，多条购买事件可能属于同一订单、不同订单或记录机制产生的多次行为，因此该指标只是事件级重复购买代理，不是真实订单复购率。

## 重复购买日率

公式：`在至少 2 个自然日发生 buy 的用户数 / 至少有 1 条 buy 事件的用户数`。自然日按转换后的 Asia/Shanghai 时间计算。

**限制：** 跨日购买比多事件条件更严格，但仍无法识别订单，也受 9 天观察窗口影响。它是购买日代理，不表示长期复购或固定复购周期。

## 类目购买/PV 行为计数比

公式：`某类目的 buy 事件数 / 该类目的 pv 事件数`。分子与分母都是行为行数，不做用户去重；比较类目时应同时展示购买数和 PV 分母。

**限制：** 该比值不是转化概率，不要求同一用户或同一商品先浏览再购买。事件计数允许一个用户多次购买，因此比值可能大于 1；当该类目 `PV = 0` 时分母为零，指标无定义，应保留为空值而不是写成 0。
