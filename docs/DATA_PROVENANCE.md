# 数据来源与抽样

本页只记录可由 `data/source_manifest.json` 追溯的来源事实、文件指纹和抽样规则。原始数据与样本文件不进入 Git。

## 来源

- 官方页面：https://tianchi.aliyun.com/dataset/649
- 下载镜像：https://www.kaggle.com/api/v1/datasets/download/marwa80/userbehavior
- 数据集许可：CC BY-NC-SA 4.0
- 官方日期窗口：2017-11-25 至 2017-12-03

CC BY-NC-SA 4.0 适用于数据集。仓库代码的许可证不能替代或重写数据集许可，使用数据时仍需遵守署名、非商业和相同方式共享要求。

## 字段

官方数据包含五列：`user_id`、`item_id`、`category_id`、`behavior`、`timestamp`。数据没有价格、金额或订单 ID，因此无法从该来源计算 GMV、客单价和真实订单复购。

## 确定性用户抽样

抽样规则是 `user_id % 100 == 0`。规则先选择用户，再保留所有入样用户的全部事件；它不是从事件行中随机抽取 1%。相同源文件和规则会得到相同用户集合，便于复现用户级行为分析。

清单记录源文件处理行数为 100,150,807，抽样后为 1,002,393 行、9,895 名用户。分析流水线再按字段和日期规则清洗，最终指标规模与原始抽样规模可能不同。

## Git 发布边界

`data/raw/`、`data/sample/`、源 ZIP、抽样文件、数据库和其他归档文件均排除在 Git 之外。公开仓库只保留来源清单、代码、SQL、测试以及由安全守卫检查过的结果与报告；本地虚拟环境和密钥文件同样不发布。
